# 📐 建築空間粉刷門窗規範與檢核系統 - AutoCAD 外掛操作流程指南 (v16.0)

本資料夾包含了 **AutoCAD (DWG) 圖面** 執行空間名稱掃描、門窗對照、門寬提取、粉刷編號框寫入與**圖塊正下方門窗圓圈標籤自動繪製**的全套 AutoLISP 外掛與完整操作手冊。

---

## 🔥 v16.0 核心功能與升級亮點

1. 🎯 **門寬尺寸 1 對 1 標頭精準解析**：
   - 支援 `.md` 中按不同門寬分別設定標籤：
     - `- **90cm門窗編號**: D008` ➔ 輸入 **`90`** 寫入 **`D008`**
     - `- **120cm門窗編號**: D0081` ➔ 輸入 **`120`** 寫入 **`D0081`**
     - `- **240門號**: D0082` (或 `- **240窗編號**: D0082`) ➔ 輸入 **`240`** 寫入 **`D0082`**
2. ⭕ **圖塊正下方門窗圓圈標籤 (Circle Tag)**：
   - 寫入粉刷編號（如 `PE08`）至空間圖塊屬性框 `<` `-` `-` `>` 後，自動於**圖塊與粉刷編號正下方**生成青色門窗圓圈符號（半徑 R=50.0），並於圓圈中心放置綠色置中文字標籤（文字高度 H=30.0）。
3. 🛡️ **單一標籤絕對輸出 Guard (Single Tag Output Guard)**：
   - 全面改進 AutoLISP 逐字元分割引擎，徹底排除多個逗號門號相連（如 `D008, D0081`）印在畫面的問題，保證圖面上**只會輸出極致乾淨的單一門號**！
4. ⚡ **已存在門標自動過濾 (Duplicate Skip Engine)**：
   - 框選區域時自動識別已經生成的門標文字，自動跳過防止重複繪製圓圈與重複計算。

## 🚀 完整操作流程步驟

### 步驟 1：載入 AutoLISP 外掛程式 (`cad_qc.lsp`)
1. 開啟 AutoCAD（支援 AutoCAD 2012 ~ 2026+ 繁中/簡中/英文版）。
2. 在命令列輸入指令 **`APPLOAD`** 並按下 Enter。
3. 瀏覽並選取 **`cad_qc.lsp`** 檔案，點擊「載入 (Load)」。
4. *(選擇性)* 將 `cad_qc.lsp` 拖曳至 APPLOAD 的「啟動組 (Startup Suite)」中，以後開啟 AutoCAD 將自動載入。

---

### 步驟 2：執行自動化檢核指令
在 AutoCAD 命令列輸入以下任一指令並按 Enter：
- **`QC`** *(推薦！最簡短指令)*
- **`CADQC`**
- **`REVITQC`**

---

### 步驟 3：輸入欲查詢之門窗寬度 (cm)
命令列會彈出提示：
`Enter Door/Window Width in cm (e.g. 90, 120, 240) <90>:`
- 輸入 **`90`**、**`120`** 或 **`240`** 並按 Enter（預設為 90cm）。

---

### 步驟 4：點選或框選圖面空間物件
1. 畫面上出現提示：`Select DWG Room Labels or Door Schedule Tags:`
2. 用滑鼠點選或框選平面圖上記錄空間名稱的**屬性圖塊**（如 `NA-ROOM` 圖塊，內含屬性 `NAME`="進氣機房"）或**文字**。
3. 按下 **Enter** 鍵完成選取。

---

### 步驟 5：成果驗證
AutoCAD 將自動執行：
1. **粉刷編號寫入圖塊**：自動將對應粉刷編號（如 `PE08`）拆解填入圖塊屬性標籤 `<` `P` `-` `E` `-` `0` `>` `8`。
2. **圖塊與粉刷編號正下方繪製圓圈標籤**：於圖塊下方 `Y - 180` 處自動繪製圓圈 (◯) 並在圓心生成選擇門寬對應之單一標籤（如 `D008` 或 `D0081` 或 `D0082`）。

## ❓ 常見問題與障礙排除 (FAQ)

- **Q1: 重新載入 .lsp 檔後如何確保吃到的資料庫是最新的？**
  - 指令 `CADQC` 與 `QC` 在每次執行時皆會自動重新讀取 `空間裝修與門窗對照表.md`，無需重開 AutoCAD。
- **Q2: 若選取範圍包含舊的門窗標籤會重複繪製圓圈嗎？**
  - 不會！v16.0 具備 Duplicate Skip Engine，會自動過濾已產生的門窗標籤，只會處理空間圖塊。
