AutoCAD (DWG) 空間規範數據庫整合應用

方法一：AutoCAD 數據提取 (DATAEXTRACTION)

在 AutoCAD 執行 DATAEXTRACTION 指令，將 DWG 中的房間名稱塊、門號標註塊屬性匯出為 CSV 檔，隨後直接上傳至本系統「Revit 數據 QC 檢核器」進行自動對照比對！

方法二：AutoLISP 圖面內一鍵檢核 (`cad_qc.lsp`)

在 AutoCAD 執行 APPLOAD 載入 cad_qc.lsp，輸入 REVITQC 指令選取圖面上的空間名稱與屬性塊，自動與規範數據庫連動對照。

方法三：DWG 空間粉刷對照表自動填寫

透過本系統導出的 CSV / Markdown 規範數據，結合 AutoCAD 表格 (TABLE) 或 Attrib Block，自動填寫 2D 施工圖面之裝修表與門窗表。
